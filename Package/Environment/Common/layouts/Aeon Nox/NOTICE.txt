Aeon Nox for this RetroFE fork
==============================

Source
------
Aeon Nox, the RetroFE theme by David Horowitz (2016), based on the Aeon Nox skin
for Kodi (see credits.txt and readme.txt, both kept as they were).

Copied from RetroFE's original repository:
  https://github.com/phulshof/RetroFE

Every file was checked against that commit's Git blob hashes.

(LICENSE.txt at the root of the repository). The fonts have their own

  - images/wall.png, floor.png, infobar1.png, infobar2.png, bar.png, topbar.png,
    system_info_bg.png, system_info_overlay.png and video_overlay.png follow the look
    of the Aeon Nox skin for Kodi by BigNoid (github.com/BigNoid/Aeon-Nox). That skin
    is not GPL: its LICENSE.txt says Creative Commons Attribution-ShareAlike 3.0 United

    ShareAlike 4.0 International (since January 2014). Upstream RetroFE doesn't say

What this fork changed
----------------------
RetroFE here builds a page for every collection, so every list is menu 0.
Upstream drew systems (menu 0) and games (menu 1) on one page; the two views are
now separate pages:

  layout.xml, layout 4x3.xml      The games view (information wall, box art), used by
                                  every collection of games without a page of its own.
                                  It now shows with onEnter as well as onMenuEnter, and
                                  its labels (Publisher, Genre...) only show with a value.
  collections/_menu/layout/       The systems view (one logo per collection). RetroFE
                                  uses it for any collection whose items are all
                                  collections, such as Main (Browse) or a "Consoles"
                                  menu, unless it has a page of its own. Collections
                                  without a logo show their name.
  collections/Home/layout/        Home (Catalog, Settings, Manage, Browse) in the systems
                                  style, with a logo, icon, tagline and description per
                                  item under collections/Home/medium_artwork/.
  collections/Catalog/layout/     The Catalog: packages in the logo strip, their kind,
                                  source and version in the info panel, and an icon and
                                  text for the Sources item under
                                  collections/Catalog/medium_artwork/.
  forms/layout.xml                Settings, Manage, Sources and the other screens, on the
                                  theme's info panel.
  forms/package/layout.xml        A package, leaving the Catalog's info panel visible.
  forms/keyboard/layout.xml       The on-screen keyboard.
  "layout 4x3.xml"                A 4:3 version of each page above, for randomLayout =
                                  layout 4x3.

These pages are generated from upstream's layout.xml and "layout 4x3.xml" by
Scripts/aeon-nox/gen_layouts.py in the RetroFE repository.

Written by hand for this fork, from the theme's images and fonts:

  collections/_videos/layout/     Video collections (info.conf type = videos): the list
                                  and the selected video playing beside it (layout.xml),
                                  and player.xml, where RetroFE plays a video full
                                  screen for a collection with play = here. Each also
                                  as a 4:3 version.

Also:
  - Fonts: BebasNeue.ttf was version 1.002 under the Dharma Type EULA, which doesn't
    allow redistribution; replaced with the OFL release. OpenSans.ttf was an
    "Open Sans Hebrew Condensed" build with no copyright or license information and
    306 characters; replaced with Open Sans Condensed (Latin, Greek, Cyrillic,
    Hebrew). fonts/MC360.ttf, actually Ubuntu Condensed 0.80 under the Ubuntu Font
    Licence (shipped without it), is removed; the games view's story text uses
    Roboto Condensed instead. License texts added for every font.
  - New artwork, all of it made by Scripts/aeon-nox/gen_images.py in the RetroFE
    repository, which draws it with Pillow from rectangles, ellipses, arcs and
    polygons whose coordinates are written in the script. No icon font, icon set or
    traced artwork was used; the shapes are the usual metaphors (a download arrow
    over a tray, a gear, sliders, a grid of tiles, a stack of disks). The script
    regenerates these files byte for byte:
      images/background.png        behind every page, where upstream was black
      images/form_focus.png        the focused row on form pages
      collections/Home/medium_artwork/logo/*.png    Home's logos: an icon and the
                                   item's name in Bebas Neue (OFL)
      collections/Home/medium_artwork/icon/*.png    Home's icons
      collections/Catalog/medium_artwork/icon/Catalog Sources.png
  - Games view: the top bar names the collection in text (upstream showed its system
    logo, which collections made in RetroFE don't have); "ITEMS" and the count no
    longer overlap; titles without box art use Oswald; MC360 replaced as above.
  - Systems view: names without a logo use Bebas Neue at a size that fits between
    logos; the video's black backing is gone, and the Browse icon shows faintly where
    a system has no video.
  - Images and sounds on collection pages are referenced relative to their folder
    (../../../images/...), so RetroFE doesn't log an error before falling back.
  - XML tidied so the files are well-formed: mismatched closing tags fixed, comment
    rules no longer contain "--", a duplicated attribute removed, minScrollTime
    spelled correctly. The 4:3 date no longer runs into the time.
  - splash.xml: same intro video; the missing Roboto-Bold.ttf reference and the
    commented-out examples are gone.
