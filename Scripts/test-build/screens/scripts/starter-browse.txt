# Builtin.cpp defaults to Home; RetroFE.cpp opens Manage when settings.conf is absent.
# Home::landing chooses Browse when collections exist. Timing: tune on CI.
# RetroFE logs nothing at its default level once the first page shows, and the
# log is rewritten as settings load, so this waits a fixed time instead.
wait 8
key F10
wait 1
shot main-menu
# Home::browse opens Main; MenuParser preserves the first-setup menu order (NES first).
key Return
wait 2
# Return enters NES (RetroFE.cpp selection); timing: tune on CI.
key Return
wait 2
shot nes-list
# Aeon Nox layout.xml has a horizontal menu; controls.conf maps Right to right.
# CollectionInfo::itemIsLess sorts by lowercase full title: Addams, Arch, Bill & Ted.
key Right x2
wait 1
shot nes-scrolled
# Return launches Bill & Ted; Launcher writes to the first-setup fake RetroArch.
key Return
wait 3
expect-file emulators/RetroArch/launches.txt Bill & Ted's Excellent Video Game Adventure (USA).nes
# Eight positions after Bill & Ted is Missing Game (CollectionInfo::itemIsLess).
key Right x8
wait 1
# RetroFE.cpp displays a launch failure notice; timing and dismissal: tune on CI.
key Return
wait 2
shot missing-game-notice
expect-log It couldn't start
# ManagerUI handles F10 to open Manage; notice interaction: tune on CI.
key F10
wait 1
shot manage-from-nes
quit
