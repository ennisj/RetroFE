# Starter test install: what a first setup would have downloaded, picked from the owner's copy of
# OneSauce (content/retrofe/collections on the OneSauce share). Only these paths are in the repo;
# the files themselves never are. See Scripts/test-build/README.md.
#
# One path per line, relative to that collections folder. A path ending in "/" is a folder, copied
# with everything in it. "=> <path>" puts the file somewhere else under the staging folder.
#
# Picked to cover: names with ", The", "&", "'", "!", "...", dots and region lists; a second extension
# (.dat on NES, .md and .smd on Genesis); a game in a subfolder (Contra); a game without artwork
# (Excitebike); artwork without a game (Metroid, puckman); artwork named after the title instead of the
# file (Genesis) or kept as a folder of pictures (Genesis, MAME); a clone whose artwork is its parent's
# (pacman, clone of puckman).
